The Awful World of [BLARIO BLARE] is a parody of Nintendo's Wario Ware franchise in which the player must complete minigames to progress through rounds. The game was developed for the Brackeys Game Jam 2025.1, which had the theme "Nothing Can Go wrong", which led to the game's main gimmick, it's randomised controls. The randomised controls play a major part in the game, with the player being punished for pressing the wrong keys with the shortening of the time they have to complete a given minigame.

Blario Blare is split into two gamemodes, Campaign and Endless.
Campaign Mode is the main portion of Blario Blare, the player is tasked with completing minigames in order to complete progressively faster rounds, which consist of ten minigames each. interspersed between rounds the game has text based cutscenes, these acting as a way to play into the Game Jam's theme. Endless Mode, on the other hand, functions as a score attack in which the round system is removed and the player is able to play minigames forever, the game speeding up more drastically each ten minigames.

The short development time envoked by the Game Jam's runtime led to a lot of the game's features being coded dynamically allowing for me to tweak elements of the game quickly. For example, dialogue runs on methods that need a few string parameters (text, sprite) and then sort themself into a text set. Achivements while needing to be set to true in the code, only require a name and value to appear in the menu. Minigames are setup to only require coding for their visuals and the conditions needed to satisfy the win condition. scoring, intermissions, win/lose conditions and speedups are all handled outside of this and don't require any alternating within minigames to work. (Achivements were coded into the initial release of the game but the button to access the menu was commented out due to the achievement ideas not being finished)
