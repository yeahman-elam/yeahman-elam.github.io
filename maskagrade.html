Maskagrade


Engine Unity
Programming Language C#
Production Time 8 weeks
Team Size 2
Role(s) Programmer, Audio
Gameplay

Maskagrade is a roguelite heavily influence from the early entries of the Zelda franchise, the game's gimmick relying on the use of masks which alter level design elements as well as the ability to upgrade your skills between each run using currency. The game was created for a college brief in which each team had to create a short game with a defined gameplay loop in order to teach trainees the required skills to make larger products.
