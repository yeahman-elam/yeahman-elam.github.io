Glue Guy


Engine Gamemaker
Programming Language GML
Production Time 3 days
Team Size 1

Glue Guy is a short puzzle platformer about an extending gluestick who can stick to ceilings, grab and toss platforms in order to complete levels. The game was made for GMTK Game Jam 2024 the theme of the jam being "Built to Scale", the inspiration for Glue Guy's whole concept.

The main technical highlight for this project would probably be the game's mechanics which all relied on state machines, checking and setting what the player was carrying in order to allow them to toss and throw objects. Objects also having setup to allow for the player to use them as platforms after being thrown. Other aspects of the game such as tutorialisation and the way its displayed also use this system, and it's use within this project was generally helpful for gaining a greater grasp on the use of states.
